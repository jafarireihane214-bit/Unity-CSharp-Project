# Unity C# Project

A complete software/game project developed using the Unity Engine and C# programming language within the Visual Studio environment.

## 🚀 Key Features
- **Core Logic:** Implemented robust application logic and mechanics using C#.
- **Environment:** Developed and managed within the Visual Studio IDE, showcasing strong integration with the Unity ecosystem.
- **Asset Management:** Structured and optimized project assets, scenes, and prefabs following Unity best practices.
- **Object-Oriented Design:** Applied OOP principles for clean, maintainable, and scalable code architecture.

## 🛠️ Technologies Used
- **Game Engine:** Unity
- **Programming Language:** C#
- **IDE:** Visual Studio
- **Version Control:** Git / GitHub

## 📂 Project Structure
- `Assets/`: Contains all scripts, scenes, prefabs, and visual assets.
- `ProjectSettings/`: Configuration settings for the Unity project.
- `.gitignore`: Configured to exclude heavy auto-generated Unity folders (Library, Temp, Builds) to ensure a clean repository.
